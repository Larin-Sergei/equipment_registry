
# Реестр учебного оборудования

Практическая работа по дисциплине **«Алгоритмы и структуры данных»**.

**Тема:** «Реестр оборудования: от хеш-функции до открытой адресации».

## Описание проекта

Консольное приложение на Python для хранения и управления сведениями об учебном оборудовании с использованием хеш-таблиц.

Каждая запись содержит:

- `id` — уникальный инвентарный номер;
- `name` — наименование оборудования;
- `room` — номер аудитории;
- `status` — состояние оборудования.

Инвентарный номер используется в качестве ключа хеш-таблицы.

## Реализованные алгоритмы

В проекте реализованы два способа разрешения коллизий.

### 1. Закрытая адресация (метод цепочек)

Элементы с одинаковым хеш-адресом размещаются в списке соответствующего бакета.

Особенности:
- Несколько записей могут находиться в одном бакете.
- Количество записей может превышать размер таблицы.
- Удаление выполняется непосредственно из цепочки.

### 2. Открытая адресация (линейное пробирование)

Все элементы размещаются непосредственно в массиве хеш-таблицы.

При возникновении коллизии выполняется поиск следующей свободной ячейки.

Особенности:
- Используется линейное пробирование.
- Для удалённых элементов применяется специальный маркер `DELETED`.
- Освободившиеся ячейки могут использоваться повторно.
- При заполнении массива добавление новых записей блокируется.

## Хеш-функция

Для вычисления индекса используется метод деления:

```python
def hash_function(self, key):
    return key % self.size
```

Где:
- `key` — инвентарный номер оборудования;
- `size` — размер хеш-таблицы.

При линейном пробировании используется формула:

`h(id, i) = (h(id) + i) % m`

где `i` — номер попытки, начиная с нуля.

## Анализ сложности

Обозначения:
- `n` — количество записей.
- `m` — размер хеш-таблицы.

| Операция | Метод цепочек (средняя / худшая) | Линейное пробирование (средняя / худшая) |
|---|---|---|
| Вставка | O(1) / O(n) | O(1) / O(m) |
| Поиск | O(1) / O(n) | O(1) / O(m) |
| Изменение | O(1) / O(n) | O(1) / O(m) |
| Удаление | O(1) / O(n) | O(1) / O(m) |

Средняя сложность O(1) предполагает равномерное распределение ключей и достаточно низкую загрузку таблицы.

Пространственная сложность:
- Метод цепочек — O(m + n).
- Линейное пробирование — O(m).
